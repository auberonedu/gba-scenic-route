# mGBA & LibreSprite Installation

We will next install mGBA, a Game Boy Advance emulator, and LibreSprite, a sprite editor

## Install mGBA

Install [mGBA](https://mgba.io/downloads.html) on your system. For Windows, choose the 64 bit installer exe. For Mac, choose the modern installer. 

mGBA emulates a Game Boy Advance - it gives us a way to test out our games on our computer before we actually write them to be played on a real Game Boy.

## Install LibreSprite

Install [LibreSprite version 1.0](https://github.com/LibreSprite/LibreSprite/releases/tag/v1.0). Although there are newer versions, as of the time of writing this guide, version 1.0 is the only one that works across all major operating systems.

Download the version needed for your OS, and then unzip it. Try running it once it is unzipped.

On newer versions of MacOS, you will get an error when you try to open LibreSprite saying that it is from an untrusted developer. Depending on your OS version, there may be a button that allows you to open it anyways. If you do not have this button, try opening it 3 times. On certain OS versions it will give you the option on the third try. If it still does not show up, follow these [instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac) on how to open the app.

We will be using LibreSprite to edit the graphics for our games!
