# Tutorial 1: Blinky

In our first tutorial we'll be going basic: just a screen that changes colors when the user presses buttons. There's a surprising amount behind this though! We'll get a chance to understand how to work with Butano, setting us up for bigger and better things.

## What we will learn?
 - Core Butano setup and loop
 - Backdrop settings
 - Handling button presses

It's gonna be a fun one~
